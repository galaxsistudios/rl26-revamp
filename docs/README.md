# RL26 Revamp knowledge base

Two halves:

| Folder | What it is |
|---|---|
| [big-ant-base/](big-ant-base/README.md) | **How Big Ant Studios' Rugby League 26 is built**: the archive, script bundle, UI, databases, career data, art, AI and the native (exe) side, as far as we've reverse-engineered it. Hand-written; update it when a new finding changes the picture. |
| [our-changes/](our-changes/README.md) | **What we changed**: one page per mod with every Big Ant file it overrides (and how much of it), database records, career files, textures and exe patches, plus a reverse index of Big Ant's files. Generated by `python tools/gen_docs.py`; rerun it after adding or changing a mod, don't edit it by hand. |

Other files here:

- [issue-tracker.md](issue-tracker.md): gameplay issues (reported → verified → fixed) and ideas.
- [game-updates/](game-updates/): what each Steam update to the game changed, and what we had to redo.
- [nrl-stadium-names.txt](nrl-stadium-names.txt), [scrum-defence-stack-graphs.lua.txt](scrum-defence-stack-graphs.lua.txt): reference notes kept for mods.

How to build and install mods is in [INSTRUCTIONS.md](../INSTRUCTIONS.md) at the repo root; each mod's README has its
own details.
