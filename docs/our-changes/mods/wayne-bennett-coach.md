# wayne-bennett-coach

Source: [mods/wayne-bennett-coach](../../../mods/wayne-bennett-coach/) - [README](../../../mods/wayne-bennett-coach/README.md)

Adds Wayne Bennett as a coach, using an AI-generated face texture (`wayne_bennett_face.png`). He takes over generic NPC **503 "Paddy Douglas"** and that NPC's tier-1 head slot, so nothing is appended and no Lua or `global.texsrc` change is needed.
