# stadium-name-fixes

Source: [mods/stadium-name-fixes](../../../mods/stadium-name-fixes/) - [README](../../../mods/stadium-name-fixes/README.md)

Corrects 24 Australasian and US stadium names on stadium select, match summaries, career previews, club home grounds and anywhere else the UI shows a ground. Where the in-game name disagreed with the commentary, the commentary name wins. The full list, with the stock names, is [docs/nrl-stadium-names.txt](../../docs/nrl-stadium-names.txt).
