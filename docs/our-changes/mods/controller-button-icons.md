# controller-button-icons

Source: [mods/controller-button-icons](../../../mods/controller-button-icons/) - [README](../../../mods/controller-button-icons/README.md)

Shows PlayStation (or any other console's) button prompts instead of Xbox ones, and lets you switch back.
