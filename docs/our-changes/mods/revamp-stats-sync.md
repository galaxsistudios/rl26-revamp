# revamp-stats-sync

Source: [mods/revamp-stats-sync](../../../mods/revamp-stats-sync/) - [README](../../../mods/revamp-stats-sync/README.md)

Keeps the base game players and clubs up to date with the RL26 Revamped stats repo, [galaxsistudios/rl26-revamped-stats](https://github.com/galaxsistudios/rl26-revamped-stats). Script mod, entry **39959**. Needs **player-import-export**, whose JSON codec, player update path and team field lists it reuses.
