# copy-academy-jerseys

Source: [mods/copy-academy-jerseys](../../../mods/copy-academy-jerseys/) - [README](../../../mods/copy-academy-jerseys/README.md)

Adds **COPY ACADEMY UNIFORM** to an Academy club's jersey list (under "New Licensed Uniform"). It lists every club of the same sex (stock official, Academy-edited official, user-created and downloaded/FanHub). Pick a club, then a jersey, and a copy is added to the club you're editing as "Jersey N".
