# nrl-field-sponsor-markings

Source: [mods/nrl-field-sponsor-markings](../../../mods/nrl-field-sponsor-markings/) - [README](../../../mods/nrl-field-sponsor-markings/README.md)

Paints NRL sponsor and round branding on the grass, laid out like a real NRL field. Everything comes from config files: one per round, saying which sponsor goes in which spot.
